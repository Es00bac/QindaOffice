# QindaQt Office documentation

M92b adds [native equation editing](equations.md) to Write and Show: shared
professional/linear editor, 23 structures, draft and document undo, native
OMML round trips, vector page/PDF rendering, and Show's compact dock workspace.

One page per library and application lands with its milestone; this index
lists what exists today.

- [Verification](verification.md) — build/test gates and the on-desktop
  manual checklist.
- [Printing](printing.md) — system printer setup, queue selection, refresh,
  failure feedback and QindaWrite page ranges, with isolated and hardware gates.
- [Decisions](decisions.md) — ADR-lite log of durable cross-cutting choices.
- [Office parity program](plans/office-parity.md) — M60–M65/D-068: Microsoft
  Office and QuickBooks interchange, measured gaps per app, milestones; the
  QindaPlan survey against Microsoft Project with its ranked gaps (M79,
  updated by M83).
- [QindaCalc](qindacalc.md) — M90/D-098: Solver, sparklines, table design,
  visibility-sensitive totals, calculated pivot fields, date filters and print assets.
- [Word interchange](word-interchange.md) — M60/D-068: QindaWrite's native
  .docx open/save, what maps, what is preserved, layout adjustments, limits;
  M70 formatting, M73 lists, numbering and styles, M77 mail merge,
  envelopes and labels, endnotes and floating pictures; M88/D-096 Word
  sections (page size, orientation, margins, headers and page numbers per
  section, section breaks); D-109 bounded rendering for long documents.
- [Mail essentials](mail-interchange.md) — M64/D-072: QindaMail's People and
  vCard/CSV, recipient autocomplete, safe HTML reading with blocked remote
  pictures, printing, and .eml / .mbox / Outlook .msg files; M76/D-085:
  Outlook data files (.pst, .ost), contact groups and CardDAV address books.
- [Organizing mail](mail.md#organizing-mail-m81) — M81/D-090: QindaMail's
  Rules and Alerts, color categories, follow-up flags, search folders,
  automatic replies (Graph, EWS, ManageSieve) and conversation clean-up;
  [M95/D-103](mail.md#everyday-mail-and-calendar-workflows-m95): Quick Steps,
  occurrence editing and calendar invitations.
- [Visio interchange](visio-interchange.md) — M65/D-073: QindaDiagram's
  native .vsdx/.vsdm/.vstx/.vstm open and save, the ShapeSheet reading,
  per-shape preservation, limits and gates; M87/D-095: what Visio's
  everyday tools store (layers, links, comments, containers, background
  pages, print setup, external data).
- [Live agent interface](agent-interface.md) — M58/M59: real Calc and Note
  state, native grants, CLI/MCP edits, receipts and revision-aware undo over QindaTK.
- [QindaNote AI](qindanote-ai.md) — M59/D-065: technical/planning/troubleshooting
  session structures, transcript-based answers and reviewed follow-ups.
- [QindaNote](qindanote.md) — M84/D-093: OneNote's everyday note-taking —
  formatted typing (styles, lists, tables, links, sanitised paste), tags and
  Find Tags, search across notebooks (Ctrl+E), import of Word, Markdown and
  HTML (OneNote `.one` refused with the way round), page templates, page
  colour, rule lines, subpages, and the versioned page format.
- [Window lifetime](decisions.md#d-056-destroy-qml-windows-before-their-required-c-objects) — why QML windows are destroyed before their host or controller.
- [Bookkeeping](books.md) — the QindaBooks engine, company file, posting
  rules, reports and I/O formats, and the app's service API.
- [Payroll tax tables](payroll-tax-tables.md) — M71/D-081: every 2026
  built-in payroll and estimated-tax value QindaBooks computes with —
  federal, and Colorado's as the first state with built-in tables — its
  source and revision date, and what still needs confirmation.
- [Diagrams](diagram.md) — the QindaDiagram drawing model, stencils,
  routing, the `.qdiagram` file, import/export and the app's canvas;
  [Visio's everyday tools](diagram.md#visios-everyday-tools-m87) (M87/D-095):
  swimlanes and containers, layers, links, comments, AutoConnect,
  Re-Layout styles, background pages, printing across sheets, external data.
- [Project planning](plan.md) — the QindaPlan scheduling engine, calendars,
  leveling, file format, Microsoft Project XML, printed output and the app;
  M79/D-088 Project's critical path options, leveling delay and options,
  baselines 0–10, the Tracking/Leveling Gantt, Network Diagram, Task Usage,
  filters and sorts; M83/D-092 task types and effort-driven scheduling,
  custom fields and formulas, elapsed durations, split and recurring tasks,
  actuals typed, progress lines, Reschedule Uncompleted Work, the Excel/CSV
  task import, recurring calendar exceptions and work weeks made here.
- [Live notes](live-notes.md) — QindaNote's automatic notes from live
  audio: capture, speech engines, the notes engine and its gate, the
  OpenCode-style provider presets and key resolution (D-057).
- [QindaBase](qindabase.md) — the database: the `.qbase` file, field
  types (file fields since M65; Hyperlink, Large Number and Calculated —
  M86), validation rules and input masks (M80), value lists and Allow Zero
  Length (M86), undo and safety, table design (the Indexes dialog — M86),
  datasheets, queries (crosstab, make-table, the Access SQL view — M80;
  union, subqueries and the four wizards — M86), forms (subforms,
  buttons, positioned controls — M89, D-097), macros (data macros, AutoExec — M86), reports (engine totals,
  labels; ten levels, Group On intervals, running sums, Keep Together and
  Force New Page — M86), import/export (Excel, CSV, XML both ways, Access,
  linked tables — D-074, D-089, D-094), templates and the service API.
