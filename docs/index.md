# QindaQt Office documentation

One page per library and application lands with its milestone; this index
lists what exists today.

- [Verification](verification.md) — build/test gates and the on-desktop
  manual checklist.
- [Decisions](decisions.md) — ADR-lite log of durable cross-cutting choices.
- [Office parity program](plans/office-parity.md) — M60–M65/D-068: Microsoft
  Office and QuickBooks interchange, measured gaps per app, milestones.
- [Word interchange](word-interchange.md) — M60/D-068: QindaWrite's native
  .docx open/save, what maps, what is preserved, layout adjustments, limits.
- [Mail essentials](mail-interchange.md) — M64/D-072: QindaMail's People and
  vCard/CSV, recipient autocomplete, safe HTML reading with blocked remote
  pictures, printing, and .eml / .mbox / Outlook .msg files.
- [Visio interchange](visio-interchange.md) — M65/D-073: QindaDiagram's
  native .vsdx/.vsdm/.vstx/.vstm open and save, the ShapeSheet reading,
  per-shape preservation, limits and gates.
- [Live agent interface](agent-interface.md) — M58/M59: real Calc and Note
  state, native grants, CLI/MCP edits, receipts and revision-aware undo over QindaTK.
- [QindaNote AI](qindanote-ai.md) — M59/D-065: technical/planning/troubleshooting
  session structures, transcript-based answers and reviewed follow-ups.
- [Window lifetime](decisions.md#d-056-destroy-qml-windows-before-their-required-c-objects) — why QML windows are destroyed before their host or controller.
- [Bookkeeping](books.md) — the QindaBooks engine, company file, posting
  rules, reports and I/O formats, and the app's service API.
- [Diagrams](diagram.md) — the QindaDiagram drawing model, stencils,
  routing, the `.qdiagram` file, import/export and the app's canvas.
- [Project planning](plan.md) — the QindaPlan scheduling engine, calendars,
  leveling, file format, Microsoft Project XML, printed output and the app.
- [Live notes](live-notes.md) — QindaNote's automatic notes from live
  audio: capture, speech engines, the notes engine and its gate, the
  OpenCode-style provider presets and key resolution (D-057).
- [QindaBase](qindabase.md) — the database: the `.qbase` file, field
  types (file fields since M65), undo and safety, table design, datasheets,
  queries, forms, reports, import/export (Excel, CSV and Access — D-074),
  templates and the service API.
